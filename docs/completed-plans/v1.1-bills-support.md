# v1.1 Bills Support

> **Release Date**: January 2026  
> **Summary**: Added bill tracking alongside subscriptions using a unified data model.

---

## Overview

SubTrkr v1.1 introduces the ability to track **bills** (utilities, rent, insurance, etc.) separately from **subscriptions** (Netflix, Spotify, etc.) while maintaining a unified view of all recurring expenses.

### Key Features
- Separate "Bills" navigation section in sidebar
- Filter tabs (All / Bills / Subscriptions) on Dashboard and Analytics
- Split category management in Settings
- Unified data model for efficient querying and maintenance

---

## Data Model Changes

### Unified Items Table

The `subscriptions` table was renamed to `items` with a new `item_type` column:

```sql
-- Before (v1.0)
CREATE TABLE subscriptions (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    ...
);

-- After (v1.1)
CREATE TABLE items (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    item_type TEXT DEFAULT 'subscription',  -- NEW: 'subscription' | 'bill'
    ...
);
```

### Category Type Scoping

Categories now have a `category_type` field to scope them to bills or subscriptions:

```sql
ALTER TABLE categories ADD COLUMN category_type TEXT DEFAULT 'subscription';
```

### Default Bill Categories

Migration 2 seeds these bill categories:
- Utilities (#f59e0b)
- Housing (#8b5cf6)
- Insurance (#3b82f6)
- Phone & Internet (#06b6d4)
- Transportation (#10b981)

### Dashboard Changes

Added `FilterTab` type with tabs:
- **All** - Shows all items combined
- **Bills** - Shows only bills
- **Subscriptions** - Shows only subscriptions

All stats, charts, and upcoming renewals filter based on selected tab.

### Analytics Changes

Same filter tabs as Dashboard, affecting:
- Monthly/yearly spending totals
- Category breakdown chart
- "Most Expensive" list (label adapts: "Most Expensive Bills" etc.)

### Settings Changes

Split into two sections:
1. **Subscription Categories** - CRUD for `category_type = 'subscription'`
2. **Bill Categories** - CRUD for `category_type = 'bill'`

## Migration Details

### Migration 2 SQL

```sql
-- Rename table
ALTER TABLE subscriptions RENAME TO items;

-- Add item_type column
ALTER TABLE items ADD COLUMN item_type TEXT DEFAULT 'subscription';

-- Add category_type column  
ALTER TABLE categories ADD COLUMN category_type TEXT DEFAULT 'subscription';

-- Recreate payments with new foreign key
DROP TABLE IF EXISTS payments;
CREATE TABLE payments (
    id TEXT PRIMARY KEY,
    item_id TEXT REFERENCES items(id) ON DELETE CASCADE,
    amount REAL NOT NULL,
    paid_at TEXT NOT NULL,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

-- Seed bill categories
INSERT INTO categories (id, name, color, category_type) VALUES
    ('cat-utilities', 'Utilities', '#f59e0b', 'bill'),
    ('cat-housing', 'Housing', '#8b5cf6', 'bill'),
    ('cat-insurance', 'Insurance', '#3b82f6', 'bill'),
    ('cat-phone-internet', 'Phone & Internet', '#06b6d4', 'bill'),
    ('cat-transportation', 'Transportation', '#10b981', 'bill');
```
